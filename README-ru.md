## Агрегаторы

Один API для многих бразильских данных.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, банки, праздники, DDD, NCM, ставки и многое другое в открытом API, который развивает сообщество. `бесплатно` `API` `открытый код`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - Праздники, CEP, CNPJ, проверка документов и другие утилиты, с бесплатным токеном. `бесплатно` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - Удалённый MCP-сервер для поиска компании по CNPJ, CEP, праздников, DDD, банков, NCM, Selic, CDI и IPCA. `бесплатно` `от автора`

## CEP и адреса

По алфавиту.

- [OpenCEP](https://go.mymarketing.click/apibr-opencep) - Бесплатный открытый API для CEP. `бесплатно` `API`
- [ViaCEP](https://go.mymarketing.click/apibr-viacep) - Бесплатный поиск по CEP в JSON и XML, без регистрации. `бесплатно` `API`

## Компании и CNPJ

- [CNPJ.ws](https://go.mymarketing.click/apibr-cnpj-ws) - API для CNPJ с бесплатной публичной версией и платными тарифами. `бесплатно` `платно` `API`
- [CNPJá](https://go.mymarketing.click/apibr-cnpja) - API для CNPJ с бесплатным публичным поиском и платными тарифами. `бесплатно` `платно` `API`
- [ReceitaWS](https://go.mymarketing.click/apibr-receitaws) - Поиск по CNPJ с бесплатным тарифом, ограниченным по числу запросов в минуту. `бесплатно` `платно` `API`

- [Dados abertos do Banco Central](https://go.mymarketing.click/apibr-dados-abertos-do-banco-central) - Портал данных BCB с рядами процентных ставок, валюты, кредита и Pix. `официальный` `бесплатно` `API`
