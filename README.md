## Agregadores

Uma API só para vários dados brasileiros.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, bancos, feriados, DDD, NCM, taxas e mais numa API aberta e comunitária. `grátis` `API` `código aberto`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - Feriados, CEP, CNPJ, validação de documentos e outros utilitários, com token grátis. `grátis` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - Servidor MCP remoto com empresa pelo CNPJ, CEP, feriados, DDD, bancos, NCM, Selic, CDI e IPCA. `grátis` `do autor`

## Etiquetas

Cada item diz o que é. As etiquetas ao lado ajudam a escolher: oficial quando vem de quem define o padrão, código aberto quando o código está publicado, grátis ou pago pelo modelo de uso, API e SDK pelo jeito de integrar. Os itens com a etiqueta "do autor" são feitos por Ciro Cesar Maciel e seguem as mesmas regras de todos os outros.
