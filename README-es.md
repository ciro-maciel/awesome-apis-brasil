Cada dirección se abrió antes de incluirse; cuando el plan gratuito tiene límite, la descripción lo indica.

## Agregadores

Una sola API para varios datos brasileños.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, bancos, feriados, DDD, NCM, tasas y más en una API abierta y comunitaria. `gratis` `API` `código abierto`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - Feriados, CEP, CNPJ, validación de documentos y otras utilidades, con token gratis. `gratis` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - Servidor MCP remoto con empresas por CNPJ, CEP, feriados, DDD, bancos, NCM, Selic, CDI e IPCA. `gratis` `del autor`

## Etiquetas

Cada elemento indica qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrar. Los elementos con la etiqueta "del autor" son hechos por Ciro Cesar Maciel y siguen las mismas reglas que todos los demás.
