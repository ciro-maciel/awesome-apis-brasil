## 어그리게이터

브라질 데이터를 여러 개 다루는 단일 API.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, 은행, 공휴일, DDD, NCM, 금리 등을 제공하는 공개 커뮤니티 API. `무료` `API` `오픈소스`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - 공휴일, CEP, CNPJ, 문서 검증 등 유틸리티를 무료 토큰으로 사용. `무료` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - CNPJ로 회사 정보, CEP, 공휴일, DDD, 은행, NCM, Selic, CDI, IPCA를 제공하는 원격 MCP 서버. `무료` `저자 작성`

## CEP와 주소

알파벳 순서.

- [ApiCEP](https://go.mymarketing.click/apibr-apicep) - 무료 요금제로 CEP 조회. `무료` `API`
- [OpenCEP](https://go.mymarketing.click/apibr-opencep) - 무료 공개 CEP API. `무료` `API`
- [ViaCEP](https://go.mymarketing.click/apibr-viacep) - JSON과 XML로 무료 CEP 조회, 가입 불필요. `무료` `API`

## 회사와 CNPJ

알파벳 순서.

- [CNPJ.ws](https://go.mymarketing.click/apibr-cnpj-ws) - 공개 무료 버전과 유료 요금제가 있는 CNPJ API. `무료` `유료` `API`
- [CNPJá](https://go.mymarketing.click/apibr-cnpja) - 무료 공개 조회와 유료 요금제가 있는 CNPJ API. `무료` `유료` `API`
- [ReceitaWS](https://go.mymarketing.click/apibr-receitaws) - 분당 제한이 있는 무료 요금제의 CNPJ 조회. `무료` `유료` `API`

## 경제와 환율

- [Dados abertos do Banco Central](https://go.mymarketing.click/apibr-dados-abertos-do-banco-central) - BCB의 데이터 포털: 금리, 환율, 신용, Pix 시계열. `공식` `무료` `API`
- [PTAX no Olinda](https://go.mymarketing.click/apibr-ptax-no-olinda) - OData로 제공하는 달러 등 주요 통화의 공식 환율. `공식` `무료` `API`
- [SGS do Banco Central](https://go.mymarketing.click/apibr-sgs-do-banco-central) - Selic, IPCA, 환율 등 수천 개 시계열을 제공하는 시계열 관리 시스템. `공식` `무료` `API`
- [Tabela FIPE](https://go.mymarketing.click/apibr-tabela-fipe) - FIPE 차량 가격표를 조회하는 API. `무료` `API` `오픈소스`

## 라벨

각 항목은 무엇인지 설명합니다. 옆의 라벨이 선택에 도움이 됩니다: 공식은 표준을 정하는 쪽에서 제공한 것, 오픈소스는 코드가 공개된 것, 무료 또는 유료는 사용 방식에 따른 것, API와 SDK는 연동 방식입니다. "저자 작성" 라벨이 붙은 항목은 Ciro Cesar Maciel이 만들었으며 다른 모든 항목과 같은 기준을 따릅니다.
