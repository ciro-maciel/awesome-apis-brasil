## लेबल

हर आइटम बताता है कि वह क्या है। बगल के लेबल चुनने में मदद करते हैं: आधिकारिक तब जब मानक तय करने वाले ने बनाया हो, ओपन सोर्स तब जब कोड सार्वजनिक हो, मुफ़्त या सशुल्क उपयोग के मॉडल के अनुसार, और API तथा SDK इंटीग्रेट करने के तरीके के अनुसार। जिन आइटम पर "लेखक का" लेबल है, वे Ciro Cesar Maciel ने बनाए हैं और बाकी सबके जैसे नियम मानते हैं।
