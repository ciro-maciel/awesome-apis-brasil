Beginnt bei den Aggregatoren, die vieles in einer einzigen API bündeln, und geht dann nach Thema bis zu den offiziellen Portalen. Jede Adresse wurde vor der Aufnahme geöffnet; wenn das kostenlose Angebot ein Limit hat, steht es in der Beschreibung.

## Aggregatoren

Eine einzige API für viele brasilianische Daten.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, Banken, Feiertage, DDD, NCM, Zinssätze und mehr in einer offenen, von der Community getragenen API. `kostenlos` `API` `Open Source`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - Feiertage, CEP, CNPJ, Dokumentenprüfung und weitere Hilfsfunktionen, mit kostenlosem Token. `kostenlos` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - Remote-MCP-Server mit Unternehmen per CNPJ, CEP, Feiertagen, DDD, Banken, NCM, Selic, CDI und IPCA. `kostenlos` `vom Autor`
