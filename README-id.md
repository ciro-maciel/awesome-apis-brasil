## Agregator

Satu API untuk banyak data Brasil.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, bank, hari libur, DDD, NCM, suku bunga, dan lainnya dalam satu API terbuka dan komunitas. `gratis` `API` `open source`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - Hari libur, CEP, CNPJ, validasi dokumen, dan utilitas lain, dengan token gratis. `gratis` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - Server MCP jarak jauh untuk perusahaan lewat CNPJ, CEP, hari libur, DDD, bank, NCM, Selic, CDI, dan IPCA. `gratis` `dari penulis`

## CEP dan alamat

Urut abjad.

- [ApiCEP](https://go.mymarketing.click/apibr-apicep) - Pencarian CEP dengan paket gratis. `gratis` `API`
- [OpenCEP](https://go.mymarketing.click/apibr-opencep) - API CEP gratis dan terbuka. `gratis` `API`
- [ViaCEP](https://go.mymarketing.click/apibr-viacep) - Pencarian CEP gratis dalam JSON dan XML, tanpa pendaftaran. `gratis` `API`

## Perusahaan dan CNPJ

Urut abjad.

- [CNPJ.ws](https://go.mymarketing.click/apibr-cnpj-ws) - API CNPJ dengan versi publik gratis dan paket berbayar. `gratis` `berbayar` `API`
- [CNPJá](https://go.mymarketing.click/apibr-cnpja) - API CNPJ dengan pencarian publik gratis dan paket berbayar. `gratis` `berbayar` `API`
- [ReceitaWS](https://go.mymarketing.click/apibr-receitaws) - Pencarian CNPJ dengan paket gratis, dibatasi per menit. `gratis` `berbayar` `API`

## Ekonomi dan kurs

Urut abjad.

- [AwesomeAPI de cotações](https://go.mymarketing.click/apibr-awesomeapi-de-cotacoes) - Kurs mata uang real-time, gratis. `gratis` `API`
- [Dados abertos do Banco Central](https://go.mymarketing.click/apibr-dados-abertos-do-banco-central) - Portal data BCB, dengan deret suku bunga, kurs, kredit, dan Pix. `resmi` `gratis` `API`
- [PTAX no Olinda](https://go.mymarketing.click/apibr-ptax-no-olinda) - Kurs resmi dolar dan mata uang lain, dalam OData. `resmi` `gratis` `API`
- [SGS do Banco Central](https://go.mymarketing.click/apibr-sgs-do-banco-central) - Sistem Pengelola Deret Waktu: Selic, IPCA, kurs, dan ribuan deret lainnya. `resmi` `gratis` `API`
- [Tabela FIPE](https://go.mymarketing.click/apibr-tabela-fipe) - API untuk mencari tabel FIPE kendaraan. `gratis` `API` `open source`

## Pemerintah dan Legislatif

Urut abjad.

- [API do Portal da Transparência](https://go.mymarketing.click/apibr-api-do-portal-da-transparencia) - Pengeluaran, kontrak, pegawai, dan tunjangan pemerintah federal, dengan token gratis. `resmi` `gratis` `API`
- [API Pública do DataJud](https://go.mymarketing.click/apibr-api-publica-do-datajud) - Metadata perkara hukum dari semua pengadilan, dari CNJ. `resmi` `gratis` `API`
- [Catálogo de APIs do gov.br](https://go.mymarketing.click/apibr-catalogo-de-apis-do-gov-br) - Katalog API pemerintah federal di Conecta gov.br. `resmi` `API`
- [Dados Abertos da Câmara](https://go.mymarketing.click/apibr-dados-abertos-da-camara) - Anggota DPR, proposisi, pemungutan suara, dan pengeluaran. `resmi` `gratis` `API`
- [Dados Abertos do Senado](https://go.mymarketing.click/apibr-dados-abertos-do-senado) - Senator, materi, pemungutan suara, dan komisi. `resmi` `gratis` `API`
- [Dados abertos do TSE](https://go.mymarketing.click/apibr-dados-abertos-do-tse) - Calon, daftar pemilih, dan hasil pemilu. `resmi` `gratis`
- [IBGE: API de serviços de dados](https://go.mymarketing.click/apibr-ibge-api-de-servicos-de-dados) - Lokasi, nama, agregat, mesh, dan berita dari IBGE. `resmi` `gratis` `API`

## Portal data terbuka

Basis data lengkap untuk diunduh atau dicari.

- [Base dos Dados](https://go.mymarketing.click/apibr-base-dos-dados) - Basis data publik Brasil yang sudah diolah dan siap di BigQuery, dengan SDK Python dan R. `gratis` `open source`
- [Brasil.IO](https://go.mymarketing.click/apibr-brasil-io) - Data publik Brasil dalam format mudah diakses, kode terbuka. `gratis` `open source`
- [Dados abertos da Anvisa](https://go.mymarketing.click/apibr-dados-abertos-da-anvisa) - Catatan obat, makanan, dan produk diatur lainnya. `resmi` `gratis`
- [dados.gov.br](https://go.mymarketing.click/apibr-dados-gov-br) - Portal Data Terbuka Brasil. `resmi` `gratis`

## Label

Setiap item menjelaskan apa itu. Label di sampingnya membantu memilih: resmi jika berasal dari pihak yang menetapkan standar, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, API dan SDK menurut cara integrasinya. Item dengan label "dari penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan semua item lain.
