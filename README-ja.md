## アグリゲーター

ブラジルの多様なデータを一つのAPIで。

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP、CNPJ、銀行、祝日、DDD、NCM、金利などを、コミュニティが運営するオープンなAPIで。 `無料` `API` `オープンソース`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - 祝日、CEP、CNPJ、書類の検証などのユーティリティを、無料トークンで。 `無料` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - CNPJ、CEP、祝日、DDD、銀行、NCM、Selic、CDI、IPCAで企業情報を取得できるリモートMCPサーバー。 `無料` `作者による`

## CEPと住所

アルファベット順。

- [ApiCEP](https://go.mymarketing.click/apibr-apicep) - 無料プランで使えるCEP検索。 `無料` `API`
- [OpenCEP](https://go.mymarketing.click/apibr-opencep) - 無料でオープンなCEP API。 `無料` `API`
- [ViaCEP](https://go.mymarketing.click/apibr-viacep) - CEP検索を無料でJSONとXML形式で、登録不要。 `無料` `API`

## 企業とCNPJ

アルファベット順。

- [CNPJ.ws](https://go.mymarketing.click/apibr-cnpj-ws) - 無料の公開版と有料プランがあるCNPJ API。 `無料` `有料` `API`
- [CNPJá](https://go.mymarketing.click/apibr-cnpja) - 無料の公開検索と有料プランがあるCNPJ API。 `無料` `有料` `API`
- [ReceitaWS](https://go.mymarketing.click/apibr-receitaws) - 無料プランで利用できるCNPJ検索（分あたりの回数制限あり）。 `無料` `有料` `API`

## 経済と為替

アルファベット順。

- [AwesomeAPI de cotações](https://go.mymarketing.click/apibr-awesomeapi-de-cotacoes) - リアルタイムの通貨レートを無料で。 `無料` `API`
- [Dados abertos do Banco Central](https://go.mymarketing.click/apibr-dados-abertos-do-banco-central) - BCBのデータポータル。金利、為替、融資、Pixのシリーズを掲載。 `公式` `無料` `API`
- [PTAX no Olinda](https://go.mymarketing.click/apibr-ptax-no-olinda) - ドルなど各通貨の公式レートをODataで。 `公式` `無料` `API`
- [SGS do Banco Central](https://go.mymarketing.click/apibr-sgs-do-banco-central) - 時系列データ管理システム（SGS）：Selic、IPCA、為替など数千のシリーズ。 `公式` `無料` `API`
- [Tabela FIPE](https://go.mymarketing.click/apibr-tabela-fipe) - 車両のFIPE価格表を照会するためのAPI。 `無料` `API` `オープンソース`

## 政府と立法

アルファベット順。

- [API do Portal da Transparência](https://go.mymarketing.click/apibr-api-do-portal-da-transparencia) - 連邦政府の支出、契約、公務員、給付金を無料トークンで。 `公式` `無料` `API`
- [API Pública do DataJud](https://go.mymarketing.click/apibr-api-publica-do-datajud) - 全裁判所の訴訟メタデータ（CNJ提供）。 `公式` `無料` `API`
- [Catálogo de APIs do gov.br](https://go.mymarketing.click/apibr-catalogo-de-apis-do-gov-br) - Conecta gov.brにある連邦政府のAPIカタログ。 `公式` `API`
- [Dados Abertos da Câmara](https://go.mymarketing.click/apibr-dados-abertos-da-camara) - 下院議員、法案、投票、支出。 `公式` `無料` `API`
- [Dados Abertos do Senado](https://go.mymarketing.click/apibr-dados-abertos-do-senado) - 上院議員、法案、投票、委員会。 `公式` `無料` `API`
- [Dados abertos do TSE](https://go.mymarketing.click/apibr-dados-abertos-do-tse) - 候補者、有権者、選挙結果。 `公式` `無料`
- [IBGE: API de serviços de dados](https://go.mymarketing.click/apibr-ibge-api-de-servicos-de-dados) - IBGEの地域、名称、集計データ、区画図、ニュース。 `公式` `無料` `API`

## オープンデータポータル

データセットをまるごとダウンロードor照会。

- [Base dos Dados](https://go.mymarketing.click/apibr-base-dos-dados) - PythonとRのSDKを備え、BigQueryですぐ使えるよう整形されたブラジルの公開データ。 `無料` `オープンソース`
- [Brasil.IO](https://go.mymarketing.click/apibr-brasil-io) - 利用しやすい形式のブラジル公開データ（オープンソース）。 `無料` `オープンソース`
- [Dados abertos da Anvisa](https://go.mymarketing.click/apibr-dados-abertos-da-anvisa) - 医薬品、食品、その他の規制対象製品の登録情報。 `公式` `無料`
- [dados.gov.br](https://go.mymarketing.click/apibr-dados-gov-br) - ブラジル公開データポータル。 `公式` `無料`

## タグ

各項目には内容を示しています。横のタグで選びやすくしています。公式は標準を定める機関から提供されるもの、オープンソースはコードが公開されているもの、無料または有料は利用形態によるもの、APIとSDKは連携方法によるものです。タグ「作者による」の項目はCiro Cesar Macielが作成し、他の項目と同じルールに従っています。
