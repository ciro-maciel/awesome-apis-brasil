Pour qui a besoin d'une donnée brésilienne dans un système et ne veut pas scraper de site. Commence par les agrégateurs, qui regroupent beaucoup de choses dans une seule API, puis passe par thème jusqu'aux portails officiels. Chaque adresse a été ouverte avant d'être ajoutée ; quand la version gratuite a une limite, la description le précise.

## Agrégateurs

Une seule API pour plusieurs données brésiliennes.

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP, CNPJ, banques, jours fériés, DDD, NCM, taux et plus encore dans une API ouverte et communautaire. `gratuit` `API` `open source`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - Jours fériés, CEP, CNPJ, validation de documents et autres utilitaires, avec jeton gratuit. `gratuit` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - Serveur MCP distant pour trouver une entreprise par CNPJ, CEP, jours fériés, DDD, banques, NCM, Selic, CDI et IPCA. `gratuit` `de l'auteur`

## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand il vient de celui qui définit la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'usage, API et SDK selon la façon de l'intégrer. Les éléments avec l'étiquette « de l'auteur » sont faits par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
