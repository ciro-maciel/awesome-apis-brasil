## 聚合器

一个 API 访问多种巴西数据。

- [BrasilAPI](https://go.mymarketing.click/apibr-brasilapi) - CEP、CNPJ、银行、节假日、DDD、NCM、利率等数据，都在一个开放的社区 API 中。 `免费` `API` `开源`
- [Invertexto API](https://go.mymarketing.click/apibr-invertexto-api) - 节假日、CEP、CNPJ、证件验证及其他实用工具，提供免费令牌。 `免费` `API`
- [CNPJ e CEP para agentes](https://go.mymarketing.click/apibr-cnpj-e-cep-para-agentes) - 远程 MCP 服务器，可通过 CNPJ 查询企业，并提供 CEP、节假日、DDD、银行、NCM、Selic、CDI 和 IPCA 数据。 `免费` `作者出品`

- [ViaCEP](https://go.mymarketing.click/apibr-viacep) - 免费查询 CEP，支持 JSON 和 XML 格式，无需注册。 `免费` `API`
